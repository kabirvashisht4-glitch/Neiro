Architecture

The whole signal chain

One AudioContext, wired once. The analyzer sits after the equalizer, so the bars react to the filters, and before the output gain, so microphone input can be visualized with the speakers silent.

Modules

What's in the box

Analysis

Real-time FFT

A 2048-point transform folded into 64 logarithmic bands, because linear FFT bins pack almost everything into the first inch of the graph.

Tone

Five-band equalizer

Shelving and peaking biquads at 60 Hz, 250 Hz, 1 kHz, 4 kHz and 12 kHz, with Flat, Bass, Vocal, Treble and Lounge presets.

Metadata

Reads your tags

A dependency-free ID3v2.2/2.3/2.4 parser pulls title, artist, album and embedded cover art straight out of the file.

Input

Microphone mode

Visualize a live source — a room, an instrument, your voice — with the output muted so nothing loops back.

Queue

Shuffle, repeat, rate

Drop a folder's worth of files anywhere on the page. Playback rate runs 0.5× to 2×; repeat cycles off, all and one.

Control

Keyboard and media keys

Full transport from the keyboard, plus Media Session metadata so your hardware play button and lock screen work.

Ship it

Two packages, no dependencies

The engine that draws everything on this page is published on its own, and the player runs from your terminal against any folder of music.

Command line

neiro-cli

Point it at a folder. It indexes the audio, serves the player on localhost and streams the files straight off your disk — nothing is copied or uploaded.

# play a folder, no install
npx neiro-cli ~/Music

# or install it once
npm i -g neiro-cli
neiro ~/Music --port 4173
Library

neiro-visualizer

The AudioEngine and canvas Visualizer as a standalone ES module. Framework-agnostic, typed, zero dependencies — it powers this page and the React app alike.

npm i neiro-visualizer

// wire an element to a canvas
engine.attach(audioEl)
viz.draw(ctx, w, h, 'bars', hue, frame)
